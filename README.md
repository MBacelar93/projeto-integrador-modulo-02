# 🎯 Desafio do Projeto Integrador (Módulo 2)

Para validar e consolidar todo o conhecimento trabalhado nas **80 horas do Módulo 2**, você deverá desenvolver o **"Dashboard Interativo de Consumo de APIs (Vanilla JS)"**.

## 1. Requisitos Obrigatórios

- [ ] Desenvolver a aplicação do zero em **JavaScript Puro (ES6+)**, sem frameworks (React, Vue, jQuery).
- [ ] Fazer a busca de dados de uma **API REST pública** (ex.: GitHub API, OpenWeather API ou JSONPlaceholder) utilizando `async/await` e `fetch`.
- [ ] Tratar explicitamente os estados da interface:
  - **Carregando** (Spinner)
  - **Sucesso** (Renderização no DOM)
  - **Erro** amigável para o usuário
- [ ] Implementar a funcionalidade de **Filtro ou Busca** com técnica de **Debounce** para otimizar chamadas.
- [ ] Utilizar **Delegação de Eventos** para manipular ações em listas dinâmicas (ex.: marcar item como favorito ou deletar).
- [ ] Persistir os dados ou preferências do usuário (como tema ou favoritos) no `localStorage`.
- [ ] Código escrito seguindo princípios de **Clean Code**:
  - Funções pequenas
  - Imutabilidade com métodos de array
  - Sem poluição do escopo global
