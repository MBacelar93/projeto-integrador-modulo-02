Requisitos Obrigatórios:
    ☐ Desenvolver a aplicação do zero em JavaScript Puro (ES6+), sem frameworks (React, Vue, jQuery).
    ☐ Fazer a busca de dados de uma API REST pública (ex: GitHub API, OpenWeather API ou JSONPlaceholder) utilizandoasync/awaitefetch.
    ☐ Tratar explicitamente os estados da interface:Carregando (Spinner),Sucesso (Renderização no DOM)eErro amigável para o usuário.
    ☐ Implementar a funcionalidade deFiltro ou Buscacom técnica deDebouncepara otimizar chamadas.
    ☐ UtilizarDelegação de Eventospara manipular ações em listas dinâmicas (ex: marcar item como favorito ou deletar).
    ☐ Persistir os dados ou preferências do usuário (como tema ou favoritos) nolocalStorage.
    ☐ Código escrito seguindo princípios deClean Code(funções pequenas, imutabilidade com métodos de array e sem poluição do escopo global)
